# Hướng dẫn sử dụng - Quản trị viên

## Tổng quan

Là Quản trị viên, bạn có toàn quyền quản lý hệ thống CarRental.

## Quản lý Người dùng

Truy cập **Admin/User** để:
- Xem danh sách tất cả người dùng
- Thay đổi vai trò (Admin, Customer, Partner)
- Khóa/Mở khóa tài khoản
- Xem chi tiết eKYC

## Quản lý Xe

- Thêm/Sửa/Xóa xe
- Duyệt xe mới
- Cập nhật trạng thái xe

## Báo cáo

Xem thống kê và báo cáo doanh thu.
